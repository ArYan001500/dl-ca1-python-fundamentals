# CA1: Python fundamentals

This repository contains the first deep learning coursework assignment. The work is a Python warm-up, so it focuses on language basics rather than model training.

## Contents

- `notebooks/python_part_1.ipynb`: strings, lists, dictionaries, boolean logic, loops, conditions, FizzBuzz, and prime-number exercises.
- `notebooks/python_part_2.ipynb`: functions and small object-oriented exercises, including `Cylinder`, `Line`, `blackjack`, `spy_game`, and `count_primes`.

## Notes

The notebooks were cleaned before upload. Outputs and personal identifiers were removed, but the exercise code was kept.
